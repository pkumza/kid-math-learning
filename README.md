# 运算王国 · 数学小课堂

这是一个纯前端的儿童数学闯关项目。每个关卡是一个独立的 `html` 文件，首页 `index.html` 作为地图入口，展示关卡与进度。

## 项目目标

- 用游戏化方式覆盖小学数学核心知识点。
- 每关控制认知负担：先探索，再练习，再挑战。
- 保持可直接预览、可快速新增关卡、无构建依赖。

## 本地运行

项目是静态页面，建议使用本地 HTTP 服务：

```bash
python3 -m http.server 8123
```

打开 [http://localhost:8123](http://localhost:8123) 即可。

## 目录约定

- `index.html`: 地图页，按分类和顺序展示关卡，统计闯关进度。
- `*.html`: 各个独立关卡页面。
- `lesson-batch-61-66.js` / `lesson-batch-61-66.css`: 配置驱动型关卡的通用引擎与样式。
- `.claude/launch.json`: 本地启动配置。

## 关卡设计总则（简版）

- 每关包含探索与闯关两个阶段，表达风格要区分，避免题面仅改数字。
- 每关提供 `3~6` 道基础闯关题，难度偏易，保障正反馈。
- 每关提供 `1~2` 道挑战题，难度提升但不跨年级。
- 每关都必须有 `💡` 提示按钮，默认隐藏提示，点击后再展示。
- 节奏建议：每 `6` 关安排 `1` 个困难关（难关）。

更完整规则见 `AGENTS.md` 与 `LEVEL_DESIGN_RULES.md`。

## 给 AI 的生成入口

当你让 AI 新增关卡时，请先让它读取：

1. `AGENTS.md`（硬约束）
2. `LEVEL_DESIGN_RULES.md`（生成模板与检查清单）
3. 参考最近关卡（命名、文案、交互风格）

推荐让 AI 按以下输出顺序提交：

1. 新关卡 `xxx.html`
2. `index.html` 入口追加
3. 自检报告（是否满足 6 个硬规则）
